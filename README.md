# Social Network RESTful API Project Structure

## Overview
This project aims to implement a RESTful API for a Social Network. The API will allow users to perform various operations such as sending friend requests, accepting/rejecting friend requests, listing friends, and listing incoming friend requests.

## Project Folder Structure
- **routes**: Contains all the route definitions.
- **controllers**: Contains controller logic for handling requests.
- **validation**: Contains validation logic for incoming requests.
- **services**: Contains service logic for interacting with the database.
- **middleware**: Contains middleware for error handling.
- **models**: Contains database models.

## Tasks to Complete
1. **Routes**:
    - All routes are pre-defined with authentication.
    - Add validation according to the routes.
2. **Validation**:
    - Implement validation logic for incoming requests in the `validation` folder.
3. **Controllers**:
    - Write API logic inside the controllers.
4. **Services**:
    - Utilize the default CRUD operations in the service file.
    - Implement proper error throwing mechanisms.
5. **Error Handling Middleware**:
    - Ensure that error handling middleware is set up to handle errors gracefully.

## API Implementation Tasks
1. **Send Friend Request**:
    - Implement the logic to send a friend request.
2. **Accept/Reject Friend Request**:
    - Implement actions to accept or reject a friend request.
3. **List Friends**:
    - Implement functionality to list a user's friends.
4. **List Incoming Friend Requests**:
    - Implement functionality to list incoming friend requests.
5. **Basic Error Handling and Validation**:
    - Implement basic error handling and validation for the API.

## Requirements
- Design and implement a RESTful API for a Social Network.
- Implement Send Friend Request, Accept/Reject Friend Request Action, List Friend, and List Incoming Friend Request functionalities.
- Implement basic error handling and validation.

## Deliverables
- Source code for the Node.js RESTful API, including routes, controllers, and data handling.
- Use a database to store the item data.
- A brief report (1-2 pages) describing the design and implementation of the API, along with any challenges faced and lessons learned during the development process.

## Evaluation Criteria
- **Functionality**: Ensure the API works as described and supports social network operations.
- **Code Quality**: Code should be well-structured, properly commented, and follow best practices for Node.js development.
- **Error Handling**: Handle errors gracefully and provide informative error messages when necessary.
